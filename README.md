# Python OOP Practice

50 hands-on questions to learn Object-Oriented Programming in Python, going from easy to brutal. Every solution is written by me, with one commit per question.

The full question list is in [QUESTIONS.md](QUESTIONS.md).

## Levels

| Level | Questions | Focus |
|-------|-----------|-------|
| 1 | Q1 to Q10 | Classes, objects, methods, `__init__`, `__str__` |
| 2 | Q11 to Q20 | Encapsulation, properties, `@classmethod`, `@staticmethod`, dunder methods |
| 3 | Q21 to Q30 | Inheritance, polymorphism, abstract classes, composition |
| 4 | Q31 to Q40 | MRO, dataclasses, context managers, iterators, descriptors, `__slots__` |
| 5 | Q41 to Q50 | Design problems: LRU cache, event bus, state machine, mini ORM, capstone |

## Structure

- `q01.py` to `q50.py`: one solution file per question
- `QUESTIONS.md`: the full list of questions

## How to run

Run any solution:

    python q05.py

Run tests (from Level 3 onward, if tests are included):

    pytest

## Rules I follow

1. Write each solution myself first.
2. Run the code before committing.
3. One commit per question.
4. Tests from Level 3, type hints and docstrings from Level 4.
